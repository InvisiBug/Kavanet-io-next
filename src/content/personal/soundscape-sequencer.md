# Soundscape Sequencer

## Overview
Soundscape Sequencer is a browser app for building layered ambient loops using simple pattern controls.

## Highlights
- Multi-track loop lanes
- Generative rhythm options
- Exportable presets for sharing

## Learning Focus
I used this project to deepen my understanding of timing drift, scheduling, and performance in the Web Audio API.

## Outcome
The app became a creative sandbox and a strong testbed for event scheduling ideas.
