# Homelab Observability Stack

## Overview
Homelab Observability Stack is a self-hosted monitoring setup for the services I run at home and in side projects.

## What It Includes
- Metrics dashboards for CPU, memory, and latency
- Centralized logs with searchable labels
- Alerting rules for downtime and response spikes

## Why I Built It
I wanted a practical way to practice production monitoring habits in a low-risk environment.

## Outcome
This project improved my incident debugging speed and helped me standardize service health checks.
