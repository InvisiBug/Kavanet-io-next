# Weekly Writing Publisher

## Overview
Weekly Writing Publisher turns local markdown drafts into a static archive with tags, search, and generated indexes.

## Core Features
- Frontmatter-based metadata parsing
- Automatic topic and date pages
- Lightweight full-text client-side search

## Tooling
The pipeline uses TypeScript scripts and a static build step that can run in CI.

## Outcome
It made publishing consistent and reduced friction between drafting and sharing.
