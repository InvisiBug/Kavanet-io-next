# Focus CLI Time Tracker

![Focus CLI Time Tracker placeholder image](/placeholders/focus-cli-time-tracker.svg)

## Overview
A command line workflow tracker designed for deep work sessions. Sessions are stored locally and exported into weekly summaries.

## Features
- Start/stop sessions from terminal commands
- Tag sessions by context or client
- Generate daily and weekly reports

## Architecture
- Local JSON storage with migration guards
- Report formatter for markdown and plain text output
- Minimal command parser with explicit options

## Outcome
This project helped me standardize my own workflow and improve consistency in personal project execution.
