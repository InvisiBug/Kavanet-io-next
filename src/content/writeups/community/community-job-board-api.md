# Community Job Board API

## Overview
Community Job Board API powers a local jobs board with a simple moderation workflow and analytics.

## Features
- Structured listing submission and review states
- Expiration policies for stale postings
- Basic usage metrics for maintainers

## Design Goals
The API prioritizes reliability, low maintenance cost, and clear contribution paths for volunteers.

## Outcome
It provided a shared backend that multiple frontend clients could consume consistently.
