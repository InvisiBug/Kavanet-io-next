# Open Data Map Nights

## Overview
Open Data Map Nights are recurring community meetups for cleaning and visualizing local open datasets.

## What Happens
- Data cleanup and normalization
- Geospatial tagging and map previews
- Public sharing of visual outputs

## Tooling
Participants use lightweight scripts and browser mapping tools to keep onboarding simple.

## Outcome
The project improves local data quality and strengthens collaboration between civic contributors.
