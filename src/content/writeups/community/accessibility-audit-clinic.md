# Accessibility Audit Clinic

## Overview
Accessibility Audit Clinic is a volunteer format where teams review websites and apps for practical accessibility improvements.

## Program Structure
- Intake and quick issue triage
- Focused remediation sessions
- Follow-up checklist and recommendations

## Deliverables
Each session ends with an issue list, severity ratings, and implementation guidance.

## Outcome
Organizations get immediate value while contributors build real accessibility review experience.
